# Privacy Policy

**Vocabulary Builder Chrome Extension**

*Last updated: January 11, 2026*

## Overview

Vocabulary Builder ("the Extension") is committed to protecting your privacy. This policy explains what data the Extension collects, how it's used, and how it's stored.

## Data Collection

### Data We Store Locally

The Extension stores the following data **locally on your device** using Chrome's storage API:

| Data Type | Purpose |
|-----------|---------|
| Saved vocabulary words | Words you choose to save for learning |
| Flashcard progress | Review history, intervals, and scores |
| Study statistics | Streak count, XP, level, review count |
| User preferences | Theme, notification settings, shortcuts |
| OpenAI API key | Only if you provide one for translation |

**This data never leaves your device** unless you explicitly use the export feature.

### Data We Do NOT Collect

- ❌ Browsing history
- ❌ Personal information (name, email, etc.)
- ❌ Analytics or usage tracking
- ❌ Cookies or identifiers
- ❌ Location data

## External Services

The Extension makes requests to external services only when you actively use lookup/translation features:

### 1. Free Dictionary API
- **URL:** `api.dictionaryapi.dev`
- **Data sent:** The word you look up
- **Purpose:** Fetch word definitions, pronunciation, synonyms
- **Privacy:** Public API, no authentication required
- **Their policy:** [dictionaryapi.dev](https://dictionaryapi.dev)

### 2. OpenAI API (Optional)
- **URL:** `api.openai.com`
- **Data sent:** Text you select for translation
- **Purpose:** Translate phrases to your target language
- **When used:** Only if you provide your own API key
- **Their policy:** [OpenAI Privacy Policy](https://openai.com/privacy)

## Permissions Explained

| Permission | Why We Need It |
|------------|----------------|
| `storage` | Save your vocabulary and settings locally |
| `activeTab` | Read text you select for lookup |
| `contextMenus` | Add "Look up" to right-click menu |
| `tts` | Pronounce words using built-in speech |
| `notifications` | Send optional study reminders |
| `alarms` | Schedule notification timing |
| `<all_urls>` | Display tooltips on any webpage |

## Data Security

- All data stored using Chrome's secure storage API
- API keys stored locally, never transmitted to our servers
- No external servers or databases operated by us
- No data synchronization or cloud backup

## Your Rights

You can:
- **Export** your data anytime (Settings → Export Data)
- **Delete** all data by removing the extension
- **Disable** notifications in extension settings
- **Remove** your API key anytime

## Children's Privacy

This Extension does not knowingly collect data from children under 13. The Extension is an educational tool suitable for all ages.
